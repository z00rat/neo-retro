# Form Component - Style Mapping

## FormItem

```
grid gap-2
data-slot="form-item"
```

## FormLabel

Uses Label component, plus:

```
font-heading
data-slot="form-label"
data-error={!!error}
```

## FormControl

```
data-slot="form-control"
```

## FormDescription

```
text-sm font-base text-foreground
data-slot="form-description"
```

## FormMessage

```
text-sm font-base text-red-500
data-slot="form-message"
```
